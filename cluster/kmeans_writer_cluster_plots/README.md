# K-Means writer–cluster membership plots

Visualizes **which writer (person) is in which K-Means cluster**, before and
after PCA, for the two clustering experiments in this project.

Generated by `cluster/kmeans_writer_cluster_visualization.py`.

## Configuration

| Version | Before PCA | After PCA |
|---|---|---|
| **V1** | StandardScaler(4096) → K-Means K=40 | StandardScaler → PCA(100) → K-Means K=40 |
| **V2** | raw 4096-D features → K-Means K=40 | raw features → PCA(95%, 30 dims) → K-Means K=40 |

- V1 uses `features/` (160 training pages, 40 writers).
- V2 uses `cluster/Clustering_v2/features/` (120 training pages, 40 writers).
- K-Means is fit **without writer labels**; labels are used only for display/evaluation.
- Cluster IDs are arbitrary; they are not writer IDs.

## Files

Each version folder (`KMeans_v1/`, `KMeans_v2/`) contains:

| File | Meaning |
|---|---|
| `KMeans_<v>_before_pca_by_writer.png` | Clustering on original features; points colored by **writer**, text = assigned **cluster ID** |
| `KMeans_<v>_before_pca_by_cluster.png` | Same clustering; points colored by **cluster**, text = **writer** |
| `KMeans_<v>_after_pca_by_writer.png` | Clustering on PCA features; points colored by **writer**, text = **cluster ID** |
| `KMeans_<v>_after_pca_by_cluster.png` | Same clustering; points colored by **cluster**, text = **writer** |
| `KMeans_<v>_writer_cluster_heatmap.png` | Writer × cluster page-count heatmap, before vs after PCA |
| `KMeans_<v>_writer_cluster_membership.csv` | Combined table: `representation`, `writer_id`, `writer`, `page_index`, `cluster_id`, `display_pc1`, `display_pc2` |

## Important note on the 2-D plots

The 2-D coordinates are **for display only**. The "before PCA" plots still
need a 2-D projection, so a PCA(2) is fitted on the same representation used
for clustering. The "after PCA" plots use the first two components of the
actual clustering PCA.

## Reproduce

```bash
python cluster/kmeans_writer_cluster_visualization.py
```
