The project at a glance

Each stage feeds the next. The repository also branches into statistical features, deep feature extraction, PCA, augmentation, transfer learning, explainability, and two clustering tracks.

06 / read before trusting

What still needs work

Interpretation guardrail: the project notes explicitly describe these results as exploratory. The held-out set has only two pages per writer, clustering is evaluated with label-based matching, and LIME explains latent features rather than human-readable handwriting traits. Treat the current best score as a direction for the next experiment, not as production accuracy.
