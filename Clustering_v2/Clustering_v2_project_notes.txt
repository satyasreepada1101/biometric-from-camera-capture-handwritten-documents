CLUSTERING_V2 — PROJECT NOTES

Purpose

This note records the current state of Clustering_v2 for the handwriting
writer-identification / writer-clustering project. It summarizes the
data, scripts, experiments, measured results, output files, and
limitations observed so far.

IMPORTANT: The numbers below are the actual outputs shared from the runs
in this conversation. They are exploratory results, not a claim that the
system is ready for reliable writer identification.

claiming real-world identification performance.

12. IMPORTANT METRIC DEFINITIONS

-   K-Means: partitions samples into K groups around cluster centroids.
-   Agglomerative Clustering: builds a hierarchy of clusters; Ward
    linkage merges groups to minimize increases in within-cluster
    variance.
-   PCA: reduces feature dimensions while retaining a specified amount
    of variance.
-   StandardScaler: standardizes each feature to mean 0 and variance 1,
    based on training data.
-   L2 normalization: rescales each sample vector to unit length.
-   Silhouette score: measures how compact and separated clusters are;
    it does not directly measure writer identity correctness.
-   ARI (Adjusted Rand Index): measures agreement between clustering and
    true labels, adjusted for chance. Higher is better; 1 means perfect
    agreement, near 0 means chance-level agreement, and negative values
    indicate worse-than-chance agreement.
-   NMI (Normalized Mutual Information): measures shared information
    between clusters and labels. Higher indicates stronger association,
    but does not alone mean that each cluster corresponds to exactly one
    writer.
-   Purity: fraction of samples that belong to the majority writer in
    each cluster. It can be inflated by using more clusters.
-   Cluster-matched accuracy: finds the best cluster-to-label matching
    using the evaluation labels. It is useful as a clustering diagnostic
    but is not a deployable prediction accuracy.
-   Train-derived writer accuracy: maps clusters to writers using
    training labels only, then predicts test writers. This is more
    realistic, but the simple majority-writer mapping can be limited if
    a cluster contains multiple writers.

Important evaluation note: The test set was used repeatedly to compare
preprocessing and configurations. Therefore, test results are
exploratory and should not be presented as an untouched final benchmark.
For a stronger final evaluation, select the pipeline using
training/validation data, freeze it, and evaluate once on a new
untouched test set if available.

13. CURRENT CONCLUSION

1.  V2 successfully extracts patch-level AlexNet features and aggregates
    them into page-level vectors.
2.  The 3-train-page / 2-test-page split is verified for all 40 writers.
3.  Raw features + PCA retaining 95% variance performed substantially
    better than StandardScaler + PCA in the tested clustering
    configurations.
4.  K-Means with K=40 and raw-feature PCA had the best train-derived
    writer-mapping accuracy among the current tested approaches
    (46.25%).
5.  Agglomerative Ward with raw-feature PCA had the strongest training
    clustering ARI (0.3208), but its test cluster-agreement and
    writer-mapping results were slightly below K-Means on some measures.
6.  The current system is an exploratory unsupervised clustering
    pipeline, not yet a reliable writer-identification system.
7.  Do not claim that cluster IDs are writer IDs. Cluster IDs are
    arbitrary; any cluster-to-writer mapping must be learned from
    training labels only for prediction.

Suggested next steps: - Keep all current outputs and scripts. - Create a
clean final comparison table from the saved CSV files. - If more model
development is needed, consider a properly supervised writer classifier
using training labels, with validation-based model selection and a final
untouched test set. That is a different experiment from unsupervised
clustering. - Inspect errors by writer and check whether the same
writer’s pages cluster together. - Record software versions, random
seeds, and exact preprocessing settings for reproducibility. - Do not
overwrite Clustering_v1 outputs.
